# Two26 Studio — статическая копия сайта

- Референс: https://two26.studio/
- Сайт: https://nastix29.github.io/chirkunova-web-game3/
- Репозиторий: https://github.com/nastix29/web_design_ref.git
  
Откройте `index.html` в браузере (Chrome / Safari / Firefox). Сборка и интернет не нужны:
шрифты, картинки и видео лежат в `assets/`.

## Страницы
- `index.html` — главная
- `work.html` — «A few projects to brag about»

## Структура
- `css/style.css` — все стили; цвета в переменных `:root`
- `js/main.js` — анимации и интерактив
- `assets/img` — фото проектов, иллюстрации, иконки, стикеры услуг, аватары
- `assets/video/hero-walkers.mp4/.webm` — анимация человечков на первом экране
- `assets/fonts` — Anton, Bricolage Grotesque, Inter Tight (лицензия SIL OFL)

## Анимации
1. Прелоадер: логотип TWO/26 рисуется линией → оранжевая арка → круг раскрывает первый экран.
2. Hero: строки заголовка выезжают из-под маски, чёрные плашки «надуваются», человечки шагают (видео, цикл).
3. Дуговая бегущая строка «Let's make it make sense • Good looks included», ускоряется от скролла.
4. «A bit about us»: текст закреплён, слова по очереди подсвечиваются оранжевым → чёрным; всплывают плашки; ярлык раздела появляется в шапке.
5. Лента иллюстраций едет вбок при скролле.
6. Карточки проектов: появление + параллакс картинки внутри.
7. «This is our thing»: «змейка» рисуется по скроллу поверх светлой дорожки, услуги и стикеры появляются по очереди.
8. Отзывы: колода закреплена, при скролле верхняя карточка улетает вверх, индикатор-риски внизу.
9. FAQ: чат-пузыри; ответ открывается пустым и «допечатывается» (текст проявляется из размытия).
10. Меню: фон затуманивается, пилюли Work / About us / Let's Talk выпрыгивают; иконка превращается в крестик.
11. Шапка над оранжевыми блоками прячет логотип, кнопка становится розовой.

## Про картинки
Изображения вырезаны из записи экрана, поэтому их разрешение — как у экрана телефона.
Для максимального качества замените файлы в `assets/img` оригиналами с теми же именами.
